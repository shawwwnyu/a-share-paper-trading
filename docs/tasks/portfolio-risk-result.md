## 行为与口径

- 账户可选 `risk` 配置随初始化冻结进账本。没有配置的旧账户不自动取得新阈值，修改外部配置文件不能改写已初始化账户。本次没有更改示例资金、私人账户、运行副本或已启用策略。
- 每次买入在账本事务内，先计算实际盘口、费用和滑点，再用当前现金及实际持仓检查总仓位、单股仓位、持仓数量、行业集中度。确认不预占现金或仓位；多个订单依次成交，后一笔读取前一笔已提交的事实。超限保留已确认待成交状态，不自动缩量。
- 仓位分母是本笔成交后的估计资产；已有持仓用本次不复权最新价估值，新增股份用最新价与含滑点成交价的较高者。现金扣除实际成交额与费用。持仓数量按有余额的股票种数统计，行业市值按冻结的分类聚合。已移出自选的持仓同样计入。
- 买入启用仓位限制时，必须提供全部持仓的本次有效行情，不能用缓存估值补缺。CLI 的 `fill` 操作新增可选 `quotes` 数组；本次成交的 `quote` 可同时用于该股票估值。重复、失效、未来、非当日行情或交易股票的矛盾报价均拒绝。行业上限启用时，任一持仓或拟买股票缺少行业分类都会阻止买入。
- 退出按“止损 → 止盈 → 持有期限 → 原均线退出”选择新建议。止损、止盈比较剩余持仓的含买入费用成本与预计卖出净收入，计入卖出费用和不利滑点；已到账分红不回加到该收益口径。无买盘时用最新价标记风险，但成交仍需有效买盘。持有期限按最早剩余批次的买入日期计算自然日。
- 生成卖出建议时结束同股未完成买入，写明结束原因；存在有效卖出建议时禁止新增加仓建议及加仓成交。保留已有卖出建议及本人决定，不替换其确认。自动退出每天每股最多一张，拒绝或过期后当天不重复提问，次日仍触发时重新确认。
- 卡片及已确认订单均先卖后买，同方向按确认时间（待确认卡片按生成时间）、编号排序。每轮仍最多发送五张新卡片；优先递送退出建议。卖出实际完成后才释放仓位。
- 退出只生成建议，确认与成交仍然分开。卡片写出实际持仓与 T+1 可卖数量；可卖数量、盘口或涨跌停条件不满足时保留委托与持仓，不制造成交。退出量最多为单笔申报上限，不自动拆单；剩余持仓留待后续日重新评估。
- `maxOrderAgeMinutes` 从信号时间计时，与原有效期取较早者。到期瞬间不再成交；`expire-orders` 将待确认和已确认的过期委托写入账本并保留原决定。日常流程在开始、取数后及结束时清理，休市也可清理。幂等重试和历史成交回放仍使用已记录事实。
- 风险退出在读取历史日线前评估；历史服务失败时仍返回已生成的退出卡片。仓位限制不强制卖出已有超限持仓，而是阻止新的风险敞口；卖出继续遵守原成交约束。

## 可选初始化字段

以下字段均位于 `account.risk`，不填表示该项不启用；数值均须为安全整数，未知字段拒绝。测试使用的阈值仅为合成案例，不是建议或本人批准的参数。

| 字段 | 含义与范围 |
| --- | --- |
| maxTotalBps | 总仓位上限，1–10000 基点 |
| maxSymbolBps | 任一股票仓位上限，1–10000 基点 |
| maxPositions | 持仓股票种数上限，1–10000 |
| maxIndustryBps | 任一行业仓位上限，1–10000 基点，须同时填写行业分类 |
| industries | 已核实的“股票代码 → 行业名称”映射；本阶段不自动抓取分类证据 |
| stopLossBps | 亏损达到此值生成退出建议，1–9999 基点 |
| takeProfitBps | 盈利达到此值生成退出建议，1–100000 基点 |
| maxHoldingDays | 持有自然日上限，1–36500 |
| maxOrderAgeMinutes | 委托有效分钟数上限，1–1440 |

现有固定股池回测未实现这些风险规则。配置风险限制的账户会明确拒绝将该回测当作候选策略通过验证的依据，保持现有策略，避免静默漏算。动态自选及一致的风险回测属于后续验证阶段。未配置风险规则的旧验证规格保留。
