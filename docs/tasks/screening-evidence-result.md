## 行为与边界

- 可选配置 `screeningEvidence` 指向本人或数据提供方核实过的证据 JSON，路径相对于账户配置文件。扫描完成后读一次文件，保存其原始数据快照、各股票评估、原始行情和目录。报告编号包含证据内容，重派同一轮使用已保存报告，不能以新文件重算既有成绩。
- 不配置文件的账户保留 `liquidity-momentum-v1` 基础观察规则；通知明确提示尚未核对完整证据。配置文件后使用 `liquidity-momentum-evidence-v2`，在原行情、成交额、换手率、市盈率、涨幅限制之上增加下表检查。它仍是待验证的观察规则，不能据此声称盈利有效，也不启用候选交易策略。首次配置和运行需在独立复核后操作，本轮没有更改任何账户设置。
- 每个证据分项均保留来源、公开时间、核对时间、失效时间和原始值。时间须带时区，公开时间不晚于核对时间，核对时间不晚于决策时间；失效瞬间即不可用于新增买入。所有日期须为真实日历日期。
- 缺失、格式错误、过期、未来资料和风险项均有逐项原因；证据缺失不等于财务良好、没有公告或没有公司行为。空公告与空公司行为列表也须明确核对覆盖区间。根对象无效、记录重复、JSON 损坏或读取失败会中止本次更新，保留账本自选；不存在静默回退。
- 行情覆盖 `complete` 仍指相对目录是否读全，与证据是否合格分开。行情不完整不替换自选；行情完整、证据全部缺失时可以得出零个合格候选，旧买入委托随退出原因结束。
- 买入建议生成及实际成交前，再用账本保存的证据核查时效，证据扫描须来自当日。证据中的已生效公司行为须先以匹配的日期、股份比例和每股净红利登记到账本，才允许新买入。筛选不自动记分红、送股或修改持仓；行业上限启用时，证据行业名称须与冻结的账户行业分类一致。已登记证据版本的账户不能用后续基础扫描静默降级。

| 分项 | 新观察规则的检查与时效 |
| --- | --- |
| 行业 | 分类体系和行业名称均必填；核对后有效期最长 366 个自然日 |
| 财务 | 报告期末不晚于公开日，距当前不超过 185 个自然日；净利润与经营现金流均须为有限正数，单位人民币元；核对后有效期最长 30 日 |
| 公告 | 覆盖最近 30 个自然日至当日，未上市部分无需覆盖；逐条保留标题、公开时间、来源及明确的风险核对结果；存在风险公告即排除；须当日核对，有效期最长 24 小时 |
| 交易状态 | 明确为正常交易，停牌、退市、未知状态排除；须当日核对，有效期最长 24 小时；恢复正常须重新取得有效证据和完整扫描 |
| 上市日期 | 至少上市 60 个自然日；核对后有效期最长 366 日；原 N/C 等名称排除仍保留 |
| 公司行为 | 覆盖最近 366 个自然日至当日，未上市部分无需覆盖；逐笔来源、生效日、股份比例和每股净到账红利；须当日核对，有效期最长 24 小时；同日多项需事先核对整合，拒绝重复日期 |

以上阈值是新版本的软件规则，尚未做样本外验证；不修改账户中已批准的均线策略和风控参数。证据来自导入方核对，程序只能验证结构、时间和规则一致性，不能证明来源内容真实或完整。当前不提供行业、财报、公告及公司行为的自动同步，也不把固定数据测试称为真实来源验收。

## 人工自选、升降级与退出

使用现有 `apply` 入口，操作编号必须稳定唯一。观察操作不代表买入决定，不产生交易确认卡片，也不自动成交：

```json
{ "type": "manual-watch", "action": "add", "symbol": "sh600000", "name": "观察名称", "reason": "本人核对后的跟踪理由", "by": "owner" }
```

- 人工添加保存观察理由和操作者。新证据规则下，仅在该股同时通过基础行情及全部证据检查时，才加入可生成建议的自选；排名落在自动前 20 名以外也可人工保留。不合格记录继续作为“仅观察”保存，不绕过证据，也不代替人工交易确认。旧基础规则下人工观察不额外取得交易资格。
- `action: "remove"` 保存人工排除理由，后续扫描继续尊重；再次 `add` 才解除排除。人工观察和排除合计不超过 100 只，自动前 20 名另计。正常日常轮询按每批最多 100 只读取快照和历史，取数完成后仍重新检查行情时效。
- 账本记录进入与退出自选的时间、原因、扫描编号，人工操作另存理由和身份；`watchlistReport` 保留最近完整扫描及所有证据评估。证据失效或风险导致降级后，结束尚未成交的买入委托，保留确认决定及结束原因。持仓、历史成交、费用、卖出委托不被删除，原 T+1 与人工确认成交约束继续生效。
- `status` 可查看完整记录；Loop 的“查看自选”区分可跟踪候选、人工仅观察和本人排除，并展示缺失或退出原因。普通私聊买卖文字仍不执行交易，也不把自由文本直接转换成自选操作。
- 旧账本重启直接恢复已有事实；缺少新增字段时使用空列表，不对旧成交或旧自选重新计算。旧账本没有新扫描报告时仍支持人工移除及结束未成交买单。

    "symbol": "sh600000",
    "industry": {

    },
    "financial": {
      "source": "合成财报来源", "publishedAt": "2026-10-30T18:00:00+08:00",
      "checkedAt": "2026-11-13T10:00:00+08:00", "validUntil": "2026-11-13T18:00:00+08:00",
      "value": { "periodEnd": "2026-09-30", "netProfit": 100, "operatingCashFlow": 120 }
    },
    "announcements": {
      "source": "合成公告核对来源", "publishedAt": "2026-11-13T09:00:00+08:00",
