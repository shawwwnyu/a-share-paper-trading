## 妙搭接入状态

机器已有飞书 CLI 1.0.100，位于 Node 24 的 bin 目录，默认 PATH 未包含它。通过飞书官方 `lark-apps` 与 CLI 内置 `lark-shared` 指南核对流程；首次认证状态返回 `not_configured`。

以独立名称 `miaoda-workbench` 发起飞书配置时，首次请求被网络沙箱拒绝。通过系统权限审核后已连接官方授权服务并取得配置链接和二维码，正在等待本人完成飞书页面配置。临时授权链接与二维码不提交仓库；配置完成后仍须验证身份并取得 `apps` 域授权。尚无妙搭应用 ID 或发布地址。

这份交付是待接入的独立网页产物，不冒充妙搭已初始化工程。后续按当前 CLI 和妙搭返回的工程规则完成：

1. 在可访问飞书的环境完成 `lark-cli config init --new`；配置完成后按 `apps` 域授权。通过官方设备授权链接完成登录，不在聊天或仓库传递凭据。
2. 本项目含 JavaScript 交互，按官方 `lark-apps` 指南选择 `frontend`。应用命名为“交易员工作台·合成演示”，不启用账户数据库。
3. 创建后保存服务端返回的 `app_id`，使用 `apps +init` 拉取工程并读取其中的领域技能和部署约定；将单文件页面接入工程真实入口，保留平台配置。不能假定本目录可以直接替代妙搭脚手架。
4. 完成工程检查与页面验收，按平台流程提交、推送并发布；只有查询发布结果为 `finished` 后，才交付返回的 `online_url`。新建前端应用不使用兼容旧 HTML 应用的 `+html-publish`。
5. 演示验收后再单独实现有身份校验的只读数据连接。当前本机接口只监听 `127.0.0.1`，不能被妙搭直接访问。
