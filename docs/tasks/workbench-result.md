## 已完成的业务与页面

- 使用 Node 自带 HTTP 服务和原生 HTML/CSS/JavaScript，实现总览、市场覆盖、观察候选、自选、人工仅观察、本人排除、委托、持仓风险、成交费用、每日及每周复盘页面。未新增运行时依赖。
- 页面只通过业务接口读取数据，没有确认、成交、修改账户或启用策略接口。本人交易决定继续在原飞书卡片处理，页面不会创建交易卡片或替本人确认。
- 新增真正只读的 `Ledger` 连接选项，跳过建表及写入设置，拒绝执行写命令。默认连接行为保留；既有业务测试、账本幂等和成交约束仍适用。读取缺失账户时不创建数据库，不以示例配置冒充账户余额。
- 当前现金、持仓及决定取自截止读取时点的账本；总资产、累计盈亏和净值取最近已记录估值，并单独显示估值时间。过期行情不换算成当前市值，缺失值显示“—”，无账户时不展示虚构余额或资料齐全。
- 市场覆盖来自最近已登记完整或不完整扫描；不完整时仍保留此前自选。候选显示记录价格、评分、行情时间、入选理由和六类证据详情，另核查当前证据是否已失效。基础版本没有完整证据时明确提示，入选不表示买入或收益已验证。
- 合格自选、人工仅观察和本人排除分别展示。人工观察理由保留；持仓不因移出自选而消失。
- 委托支持状态筛选，保留真实账本状态及截至当前的到期/策略变化状态。已到期但未登记清理的批准不算作当前待确认；详情保留本人决定、确认时间、原始依据与最近已记录未成交检查原因。
- 持仓展示实际数量、T+1 可卖数量、含费成本、有效市值、仓位、行业及行情时间，区分当前风险资料和最近已记录风险快照。成交详情展示佣金、税费、过户费及不利滑点。
- 净值图支持最近 7 日、30 日和已展示全部记录，只使用最近 365 个已记录点，不补造不存在的曲线。复盘支持每日/每周和日期选择，展示资金口径、确认延迟、未成交原因、风险及两种入退场归因；旧报告缺少统计时保留未知，不当作零次。
- 数据加载失败时保留上一成功内容并提示；页面使用文本节点展示业务文字，未插入资料中的 HTML。布局包含窄屏适配、原生表单、表格说明和原生详情对话框，但其浏览器表现仍待实际验收。

## 本地入口

使用本人核对过的配置时：

```bash
node src/cli.ts workbench /私人目录/account.json 8787
```

服务只监听 `127.0.0.1`，按启动时打印的本机地址访问。账户资料不会被复制到网页静态目录。页面刷新只重读账本和报告，不抓取新行情。可选端口为 0 时由系统分配，使用实际打印的地址。

无需读取私人账户即可验收界面，运行独立合成演示：

```bash
node scripts/workbench-demo.ts 8787
```

演示自行创建本次临时数据库及报告，所有行情、股票名称、证据和交易建议均为合成。页面持续显示“合成演示资料”，时间固定为 2026-11-13 14:30，不能据此判断真实市场或收益。演示覆盖两个持仓、当日不可卖数量、两笔待确认、一笔已确认未成交、一笔已到期未清理、合格候选、仅观察、持续排除和已保存日报/周报。按 Ctrl+C 结束后清理本次临时目录。本轮没有将演示数据库、配置或报告提交到仓库。

后台验收时不要假定另一台设备的 `127.0.0.1` 指向接单机器，也不要假定桌面会话已经带入本轮。应先恢复本轮实际可用的浏览器入口，再使用该入口能够访问的本机地址；本轮没有配置远程转发或对外发布。

## 接口边界

- `GET /api/workbench`：返回资金、最近估值、市场覆盖、最多前 100 名合格候选、当前自选、人工观察与排除、最近 200 条及全部未结束委托、最近 100 笔成交、持仓风险、最近 365 个估值点及最近 90 份日报/周报索引。
- `GET /api/reports/daily/YYYY-MM-DD` 与 `GET /api/reports/weekly/YYYY-MM-DD`：按固定目录及真实日期读取复盘，仅返回白名单业务字段；不返回原始配置、数据库/报告路径、凭据或确认者身份。
- 支持 GET/HEAD，其他方法一律拒绝；只接受本机主机名、同源访问，拒绝外站来源及跨站请求。响应不缓存，限定同源脚本及资源。静态文件按固定清单提供，不提供账户、数据库、源码或版本记录目录。
- 报告路径限于已配置报告目录，拒绝报告文件符号链接、目录外路径及路径穿越、未来日期、损坏报告和任意文件读取。缺失字段显示未知，不以新逻辑补造旧报告。

服务不提供面向外部网络的账户登录或发布能力。本轮未将服务接到运行账户，也未更改已有运行规则。
